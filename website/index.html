Project Overview

This project demonstrates how to deploy a highly available static website on Google Cloud using Cloud Storage as the origin, an HTTPS Load Balancer, and Cloud CDN for global content delivery.

Cloud Services

Cloud Storage

Hosts HTML, CSS, JavaScript and images.

Cloud CDN

Caches content at Google's edge locations.

HTTPS Load Balancer

Global entry point with SSL termination.

Certificate Manager

Automatic TLS certificate provisioning.

Cloud DNS

Maps the domain name to the load balancer.

Terraform

Infrastructure as Code for reproducible deployments.

Features

  • Static website hosting
  • HTTPS enabled
  • Global CDN caching
  • Infrastructure as Code
  • Low-cost architecture
  • Highly scalable
  • Production-inspired design

Deployment Workflow

  1. Create Cloud Storage bucket
  2. Upload website files
  3. Create Backend Bucket
  4. Configure HTTPS Load Balancer
  5. Enable Cloud CDN
  6. Create Managed SSL Certificate
  7. Deploy with Terraform
